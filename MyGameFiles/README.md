# Add game files

Put your own `prod.keys` in `keys/`.
Put your own NSP files in the applicable game folder.
You can keep the original file names.

- `silksong/`: the base NSP and the v655360 update NSP.
- `rhythm-heaven/`: the v0 base NSP.

The launcher checks the actual game modules. A file name does not replace the version check.
If there is more than one candidate file, the launcher asks you to select one.
The games and keys in this folder do not go into Git.
When you are ready, go back to the top level. Double-click `Touchable.command`.
